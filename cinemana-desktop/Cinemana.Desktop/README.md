# سينمانا Desktop — 0.4.0

تطبيق WPF عربي. **زر مشاهدة يشغّل الفيديو مباشرة داخل نافذة التطبيق نفسها بمحرك VLC مدمج. لا يفتح صفحة سينمانا ولا متصفحًا ولا برنامج VLC خارجيًا.**

## المشاهدة
- تشغيل تلقائي للفيلم أو الحلقة بعد الضغط على مشاهدة.
- جودة قابلة للاختيار بحسب ما توفره الخدمة، مع الاحتفاظ بالموضع عند تغييرها.
- تشغيل وإيقاف، تقديم وتأخير 10 ثوانٍ، شريط تقدم، صوت وكتم.
- استئناف تلقائي من آخر موضع محفوظ، وزر للعودة إلى ذلك الموضع.
- ترجمة عربية وإنجليزية عند توفرها، مع دعم SRT وWebVTT وعرض النص داخل المشغّل.
- زر الحلقة التالية عند توفر حلقة لاحقة.
- عودة إلى المكتبة داخل النافذة نفسها، وملء الشاشة عبر F11 والخروج عبر Escape.
- اختصارات Space للتشغيل والإيقاف، والأسهم للتقديم والتأخير، وM للكتم عندما يكون التركيز على سطح الفيديو.

## المكتبة
الأفلام والمسلسلات والبحث المباشر والمفضلة والسجل والتفاصيل والمواسم والحلقات والإعدادات. الفلاتر والترتيب تخص الصفحة الحالية. القوائم والصور محفوظة مؤقتًا للتصفح عند انقطاع الشبكة؛ بث الفيديو يحتاج اتصالًا مناسبًا.

## التشغيل والتثبيت
شغّل `app/Cinemana.Desktop.exe` من حزمة release-downloads، أو نفّذ `Install.ps1` للتثبيت للمستخدم الحالي وإنشاء اختصارات. النسخة المحمولة Windows x64 وتتضمن .NET ومحرك VLC. لا تحتاج WebView2 أو تثبيت VLC منفصلًا. احتفظ بمجلد التطبيق كاملًا، بما فيه `libvlc`.

قد يستغرق تجهيز محرك الفيديو بعض الوقت في أول تشغيل. تتم التهيئة في الخلفية مع بقاء الواجهة مستجيبة، ويعاد استخدام المحرك للعناوين التالية.

## تنزيل الأفلام والمسلسلات
1. من تفاصيل العنوان اضغط «تنزيل الفيلم / المسلسل»، أو زر التنزيل بجانب حلقة محددة، أو «تنزيل» داخل المشغّل.
2. اختر الفيلم/الحلقة، أو الموسم، أو «المسلسل كاملًا • كل المواسم».
3. اختر جودة محددة، أو أفضل جودة لكل حلقة، أو «جميع الجودات المتاحة». الخيار الأخير ينزّل نسخة مستقلة لكل جودة متاحة لكل حلقة، حتى لو اختلفت الجودات بين الحلقات.
4. اختر مجلد الحفظ واضغط «معاينة ملفات التنزيل». يظهر عدد الملفات والحلقات وأي جودة غير متاحة، قبل البدء.
5. اختر لغة «الترجمة» (العربية أو English أو بدون). تُحفظ الترجمة بجانب كل حلقة كملف `.srt` بنفس اسم الفيديو فيعرضها VLC والمشغّلات وأجهزة التلفاز تلقائيًا.
6. اضغط «بدء التنزيل». تُعالج الملفات بالتتابع مع عرض التقدم والحجم والسرعة، وإيقاف مؤقت ومتابعة وإلغاء وإعادة محاولة.

تُنظّم ملفات المسلسل في مجلد باسمه ثم مجلدات المواسم والجودات، وبأسماء تتضمن رقم الموسم والحلقة ومعرّف العنوان. لا يستبدل التطبيق ملفًا مكتملًا موجودًا. تُحفظ البيانات الجزئية باسم `.part` وملف جانبي `.download.json` للاستئناف عبر HTTP Range والتحقق من حجم ومصدر الملف. لا تحذف الملف الجانبي إذا أردت المتابعة. إلغاء مهمة يحتفظ بالجزء الموجود؛ لا يُحذف تلقائيًا.

إغلاق نافذة التنزيلات لا يوقف القائمة ما دام التطبيق مفتوحًا. إغلاق التطبيق يوقف التنزيلات ويحفظ القائمة؛ بعد إعادة فتحه اضغط «متابعة المتوقف». لا تستأنف التنزيلات تلقائيًا عند التشغيل. يتم جلب روابط مصادر جديدة عند بدء كل مهمة أو إعادة محاولتها دون حفظ روابط الفيديو الموقّعة في قائمة التنزيل.

التنزيل يدعم ملفات الفيديو المباشرة MP4 وMKV وTS التي توفرها الخدمة. قوائم HLS ليست ملفات فيديو مستقلة، فلا تُحفظ كملفات MP4. حجم الملف النهائي يُعرض عندما تعلن عنه استجابة الخادم؛ لا يعرض التطبيق تقديرًا غير موثوق لحجم مجموعة كاملة. يبقى توفر الملفات خاضعًا للخدمة والاتصال.
## البيانات المحلية
المفضلة والسجل والإعدادات في `%LOCALAPPDATA%/Cinemana.Desktop` وتبقى متوافقة مع 0.2.0. لم تعد ملفات جلسة المتصفح القديمة مستخدمة؛ لم يُحذف أي منها. روابط الفيديو والترجمة تُجلب مباشرة من الخدمة عند بدء المشاهدة، ولا تُحفظ في سجل المشاهدة.

## البناء والاختبارات
```powershell
dotnet build Cinemana.Desktop/Cinemana.Desktop.csproj -c Release
dotnet run --project Cinemana.Desktop.Tests -c Release
dotnet run --project Cinemana.Desktop.Tests -c Release -- --live
dotnet publish Cinemana.Desktop/Cinemana.Desktop.csproj -c Release -r win-x64 --self-contained true -o Cinemana.Desktop/release-downloads/app
```
يمكن فتح عنوان محدد من سطر الأوامر: `Cinemana.Desktop.exe --play 3147647`.

## مصادر التقنية وحدود الخدمة
المشغّل يستخدم [LibVLCSharp](https://docs.videolan.me/libvlcsharp/docs/home.html)، والواجهة WPF. تأتي بيانات المحتوى ومصادره من مسارات الموقع الحالية غير الموثقة، وقد تتغير. توفر الفيديو والجودة والترجمة يعتمد على الخدمة والاتصال، ولم تُختبر كل العناوين والصيغ. عند رفض الخدمة الوصول، يعرض التطبيق الخطأ دون تجاوز القيود.

راجع VALIDATION.md لنتائج التحقق، وTHIRD-PARTY-NOTICES.md للمكتبات المرفقة.
