# TikTok Username Checker

سكربت Python يفحص يوزرات تيك توك ويطبع المتاح منها فقط. لا يحتاج أي مكتبات خارجية (Python 3.8+).

## الاستخدام

```bash
# فحص يوزرات محددة
python check_tiktok.py yousef yousef.dev yousef_01

# فحص قائمة من ملف (يوزر في كل سطر)
python check_tiktok.py -f names.txt

# توليد 30 يوزر عشوائي: "yo" + 3 أحرف/أرقام
python check_tiktok.py --generate 3 --count 30 --prefix yo
```

المتاح يُحفظ في `available.txt`.

| الخيار | الوصف |
|---|---|
| `-d / --delay` | ثواني بين كل طلب (الافتراضي 2). تقليلها يعرّضك للحظر المؤقت |
| `--chars` | الحروف المستخدمة في التوليد (الافتراضي a-z0-9) |
| `--prefix` / `--suffix` | نص ثابت قبل/بعد الجزء العشوائي |
| `-o` | ملف حفظ اليوزرات المتاحة |

## ملاحظات
- النتيجة `AVAILABLE` تعني أنه لا يوجد حساب بهذا الاسم. بعض الأسماء محجوزة أو لحسابات محظورة ولا يمكن أخذها، لذلك تأكد من التطبيق نفسه (الملف الشخصي ← تعديل ← اسم المستخدم).
- `UNKNOWN` تعني أن تيك توك أرجع كابتشا أو حظر مؤقت؛ زد قيمة `--delay` وأعد المحاولة.
- شروط الاسم: 2 إلى 24 حرف، أحرف إنجليزية وأرقام و `_` و `.`، ولا ينتهي بنقطة.
