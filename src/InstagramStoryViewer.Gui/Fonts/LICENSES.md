# Bundled fonts

| Font | Files | License |
|---|---|---|
| [Cairo](https://fonts.google.com/specimen/Cairo) | `Cairo-*.ttf` | SIL Open Font License 1.1 |
| [Material Icons Round](https://fonts.google.com/icons) | `MaterialIconsRound.otf` | Apache License 2.0 |

Both fonts are embedded as WPF resources so the app looks the same on every Windows machine,
regardless of which fonts are installed.
